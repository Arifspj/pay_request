# Data Safety Declaration — Google Play Console

## Data Collected

| Category | Data Type | Collected? | Shared? | Purpose |
|----------|-----------|------------|---------|---------|
| Personal info | Name, phone number (contacts) | Yes (on-device only) | No | Lets user select recipients for payment requests |
| Financial info | Payment request amounts | Yes (on-device only) | No | Core app functionality — creating payment requests |
| Photos/Videos | Invoice images | Yes (on-device only) | No | Optional invoice attachment to requests |
| App activity | Payment request history | Yes (on-device only) | No | History tracking, export feature |
| Device ID | None | No | — | — |
| Location | None | No | — | — |

## Data Security
- All data is encrypted at rest via Android device storage
- No data is transmitted to external servers
- No analytics SDKs or crash reporting tools
- No third-party data sharing
- No account creation required
